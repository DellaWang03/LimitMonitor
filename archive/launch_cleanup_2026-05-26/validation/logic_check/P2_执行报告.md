### 任务描述
修改 `src/stage0/stage0_processor.py::query_virtual_issuer_addition()`，实现与 M 代码一致的 anti-join 筛选逻辑。

### M 代码逻辑（阶段0_query.md 第209-218行）
```powerquery
合并的查询 = Table.NestedJoin(更改的类型, {"发行人名称"}, 
    原始风控部债券池_主体, {"发行人名称"}, "原始风控部债券池_主体", 
    JoinKind.LeftOuter),

#"展开的"原始风控部债券池_主体"" = Table.ExpandTableColumn(合并的查询, 
    "原始风控部债券池_主体", {"发行人名称"}, 
    {"原始风控部债券池_主体.发行人名称"}),

筛选的行 = Table.SelectRows(#"展开的"原始风控部债券池_主体"", 
    each ([原始风控部债券池_主体.发行人名称] = null))
```

**逻辑说明**:
1. 将「虚拟添加」表与「原始风控部债券池_主体」按「发行人名称」左连接
2. 筛选连接结果为 null 的行（即不在原始池中的主体）
3. 这是标准的 anti-join 操作

### Python 实现（修改后）
```python
# 获取原始池中的唯一(发行人名称, 主体池)组合
df_original_pool = self.cache.get('原始风控部债券池_主体')
if df_original_pool is None:
    df_original_pool = self.query_original_issuer_pool()
    self.cache['原始风控部债券池_主体'] = df_original_pool

if len(df_original_pool) > 0:
    # 获取原始池中的唯一发行人名称
    original_keys = df_original_pool[['发行人名称']].drop_duplicates()
    
    # 与虚拟添加表左连接（键：发行人名称）
    df = df.merge(
        original_keys.assign(in_original=1),
        on='发行人名称',
        how='left'
    )
    
    # 筛选不在原始池中的主体（in_original为null）
    df = df[df['in_original'].isna()].copy()
    df = df.drop(columns=['in_original'])
    
    logger.info(f"  Anti-join筛选后: {filtered_count} 条记录")
```
