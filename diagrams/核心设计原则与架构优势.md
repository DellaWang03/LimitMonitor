# 核心设计原则与架构优势

## 核心设计原则

- **分层解耦**：各层职责单一，互相通过接口通信
- **流水线处理**：3阶段 ETL 顺序执行，数据逐层加工
- **配置驱动**：限额参数与数据源路径均外部化配置
- **无状态设计**：Web 层无状态，所有数据落盘存储
- **可追溯性**：历史数据按日归档，支持时间回溯

## 架构优势

- **轻量化部署**：无需数据库服务器，仅依赖 Python 环境
- **易于维护**：逻辑清晰分层，模块职责单一
- **可扩展性**：新增限额维度仅需扩展 Stage1/2
- **数据可追溯**：按日归档，满足审计要求
- **开发效率高**：Python 生态丰富，代码简洁
