## Stage0（Excel Power Query）10张底表：M-code逻辑梳理（无问答版）

> 用途：用于生成可视化图片（流程图/血缘图/口径卡片）。  
> 黄金标准来源：`sample data/阶段0_query.md`。

### 1. 调整实控人名单
#### 输入
- `德勤-主体评级列表.xlsx` / `Sheet1`（Excel.Workbook）

#### 关键步骤（M-code）
- 提升表头：`Table.PromoteHeaders`
- 类型转换：`Table.TransformColumnTypes`
- 选列：`主体名称`、`社会信用代码`、`主体wind代码`、`调整后实际控制人`（`Table.SelectColumns`）
- 去重：`Table.Distinct`
- 左连接：按 `社会信用代码` 关联 `调整实控人_北京国有资本` 的 `统一社会信用代码`（`Table.NestedJoin` + `JoinKind.LeftOuter`）
- 展开并覆盖：北京国资表的 `调整后实际控制人` 非空则优先使用，否则用原值（`Table.ExpandTableColumn` + 条件列）

#### 输出
- 主体维度的“调整后实际控制人”基础表（用于后续实控人穿透）

#### 输出

### 3. 风控部债券池
#### 输入
- Access：`风控部债券池.accdb` / 表 `风控部债券池`（`Access.Database`）

#### 关键步骤（M-code）
- 取最新日期快照：`List.Max([日期])` + `Table.SelectRows`（只保留最新日期）
- 类型转换：`日期` 转 `date`
- 新增标准代码列 `代码`：按 `市场名称` 给 `债券代码` 拼接后缀  
  - 银行间→`.IB`，上交所→`.SH`，深交所→`.SZ`，其他→`.BJ`
- 类型转换：`代码` 转 `text`

#### 输出
- 最新日期的债券池快照 + 标准化代码列 `代码`

---

### 4. 原始风控部债券池_主体
#### 输入
- 引用查询：`风控部债券池`

#### 关键步骤（M-code）
- 选列：`日期`、`发行人名称`、`主体池`
- 去重：`Table.Distinct`

#### 输出
- 原始主体池（从债券池快照抽取并去重）

---

### 5. 风控部债券池_主体_虚拟添加
#### 输入
- 内嵌表：`Table.FromRows(Json.Document(Binary.Decompress(Binary.FromText(...))))`
- 引用查询：`原始风控部债券池_主体`

#### 关键步骤（M-code）
- 类型转换：`发行人名称/主体池` 为 text，`变动日期` 为 date
- 左连接：按 `发行人名称` 关联 `原始风控部债券池_主体`（`JoinKind.LeftOuter`）
- 展开并筛选：仅保留连接结果为 null 的行（即“原始池不存在的发行人”）

#### 输出
- “虚拟添加主体”清单（已按 anti-join 排除原始主体池中存在的发行人）

---

#### 输入
- 引用查询：`风控部债券池`

#### 关键步骤（M-code）
- 选列：`日期`
- 去重：`Table.Distinct`

#### 输出
- 债券池日期集合（用于对齐后续“虚拟添加_每日”的日期范围）

---

### 7. 风控部债券池_主体_虚拟添加_每日
#### 输入
- `标准日期表.xlsx` / `标准日期表`（只取 `日期`）
- 引用查询：`风控部债券池_主体_虚拟添加`
- 引用查询：`债券池日期`

#### 关键步骤（M-code）
- 仅保留本年度日期：`Date.IsInCurrentYear([日期])`
- 每日展开（累积逻辑）：对每个日期筛选 `变动日期 <= 当日` 的记录，按 `变动日期` 升序后取 `Table.Last`
- 展开得到当日有效的 `发行人名称/主体池`
- 右连接对齐债券池日期：与 `债券池日期` 做 `JoinKind.RightOuter`（只保留债券池存在的日期）
- 删除嵌套列：移除 `债券池日期`

#### 输出
- 虚拟添加主体的“按日生效”结果（本年范围 + 对齐债券池日期）

---

### 8. 风控部债券池_主体
#### 输入
- 引用查询：`风控部债券池`
- 引用查询：`风控部债券池_主体_虚拟添加_每日`

#### 关键步骤（M-code）
- 从债券池抽取：`日期/发行人名称/主体池` 并 `Distinct`
- 追加合并：`Table.Combine({原始主体池, 虚拟添加_每日})`
- 去重：`Table.Distinct`
- 过滤：`主体池 <> null` 且 `主体池 <> ""`

#### 输出
- 最终主体池（原始主体池 + 虚拟添加每日展开后的修正结果）

---

### 9. 公司净资产_手工
#### 输入
- `净资产.xlsx` / `净资产` Sheet

#### 关键步骤（M-code）
- 提升表头：`Table.PromoteHeaders`
- 类型转换：`日期` 为 date，`净资产（万元）` 为 number
- 选列：`日期`、`净资产（万元）`
- 重命名：`日期 → 变动日期`，`净资产（万元） → 公司净资产(万)`

#### 输出
- 净资产“变动记录表”（变动日期粒度）

---

### 10. 公司净资产_手工_每日
#### 输入
- `标准日期表.xlsx` / `标准日期表`（只取 `日期`）
- 引用查询：`公司净资产_手工`

#### 关键步骤（M-code）
- 每日展开：对每个日期筛选 `变动日期 <= 当日` 的净资产记录，按 `变动日期` 升序后取 `Table.Last`
