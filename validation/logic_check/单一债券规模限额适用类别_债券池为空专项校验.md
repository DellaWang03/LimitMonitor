# 单一债券规模限额适用类别 - 债券池为空专项校验报告

**校验日期**: 2026-02-06  
**问题来源**: 可视化界面发现 113 条「国企」、5 条「非国企」的 单一债券规模限额指标值 为 NaN  
**根本原因**: Python 在债券池为 null 时与 M 代码输出不一致

---

## 1. 问题描述

在「限额明细_债券持仓明细表_信用债1_2」中：
- **单一债券规模限额指标值** 通过左连接从配置表「单一债券规模限额」获取
- 连接键：`(日期, 单一债券规模限额适用类别)` → `(日期, 指标名称)`
- **配置表中所有 指标名称 均为带尾斜杠形式**：`"国企/"`、`"国企/A"`、`"非国企/"`、`"可转债/"` 等

当债券池为空时：
- **Python 输出**: `"国企"`、`"非国企"`、`"可转债"` 等（**无尾斜杠**）
- **M 代码输出**: `"国企/"`、`"非国企/"`、`"可转债/"` 等（**有尾斜杠**）

导致：
- Python 的 `"国企"` 无法匹配配置表的 `"国企/"`
- 左连接失败 → **单一债券规模限额指标值 = NaN**
- 影响 113 条「国企」、5 条「非国企」债券

---

## 2. M 代码行为分析

### M 代码实现（sample data/阶段1_query.md 第435-448行）

```m
已添加条件列 = Table.AddColumn(..., "自定义", each 
    if [债券分类2] = "转债交债" then [债券类型1] 
    else if [发行人类型_调整] = "国企" then "国企" 
    else if [发行人类型_调整] = "非国企" then "非国企" 
    else null)

复制的列 = Table.DuplicateColumn(已添加条件列, "债券池", "债券池 - 复制")

合并的列 = Table.CombineColumns(复制的列,
    {"自定义", "债券池 - 复制"},
    Combiner.CombineTextByDelimiter("/", QuoteStyle.None),
    "已合并")

重命名的列 = Table.RenameColumns(合并的列,{{"已合并", "单一债券规模限额适用类别_1"}})

已添加条件列4 = Table.AddColumn(重命名的列, "单一债券规模限额适用类别", 
    each if [中债隐含评级] = "AAA" then "中债隐含评级AAA" 
    else if [中债隐含评级] = "AAA+" then "中债隐含评级AAA+" 
    else [单一债券规模限额适用类别_1])
```

### 关键行为：Table.CombineColumns

- **特性**: `CombineColumns` 是**无条件**用分隔符连接指定列
- **null 处理**: Power Query 中 null 被视为**空字符串**
- **结果**:
  - 债券池 = "A" → `"国企" & "/" & "A"` → **"国企/A"**
  - 债券池 = null → `"国企" & "/" & ""` → **"国企/"**（尾斜杠仍保留）

**即：无论债券池是否有值，M 始终产生带 "/" 的字符串**

## 3. Python 当前实现

### 代码位置：src/stage1/stage1_limit_detail.py 第92-108行

```python
# 合并债券池
if '债券池' in df.columns:
    df['单一债券规模限额适用类别_base'] = df.apply(
        lambda row: f"{row['单一债券规模限额适用类别_base']}/{row['债券池']}" 
        if pd.notna(row.get('债券池')) else row['单一债券规模限额适用类别_base'],
        axis=1
    )

# 处理中债隐含评级
df['单一债券规模限额适用类别'] = df.apply(
    lambda row: f"中债隐含评级{row['中债隐含评级']}" 
    if pd.notna(row.get('中债隐含评级')) and row['中债隐含评级'] in ['AAA', 'AAA+']
    else row['单一债券规模限额适用类别_base'],
    axis=1
)
```

### 问题

- Python 用 **条件判断**: `if pd.notna(债券池)` 才拼接
- 债券池为 null/NaN 时走 **else 分支**，保留 base 不做拼接
- 结果：债券池为空时得到 **"国企"** 而非 **"国企/"**

## 5. 数据验证

### 配置表「单一债券规模限额」中的 指标名称

```
'可交换债/'、'可交换债/A'、'可交换债/B'、'可交换债/C'、'可交换债/高收益'
'可转债/'、'可转债/A'、'可转债/B'、'可转债/C'、'可转债/高收益'
'国企/'、'国企/A'、'国企/B'、'国企/C'、'国企/高收益'
'非国企/'、'非国企/A'、'非国企/B'、'非国企/C'、'非国企/高收益'
```

**结论**: 配置表中**所有基础类别都带尾斜杠**（如 `"国企/"`），无不带斜杠的 `"国企"`

### Stage1 输出中的实际情况

```
单一债券规模限额适用类别 统计:
  "国企" (无斜杠): 113 条 → 单一债券规模限额指标值 = NaN
  "非国企" (无斜杠): 5 条 → 单一债券规模限额指标值 = NaN
  "国企/A"、"国企/B"、"国企/C" 等有值的: 均能正确匹配配置表
```

**结论**: 债券池为空时 Python 产生的无斜杠适用类别**无法匹配配置表**，导致 118 条记录缺失限额指标值

## 6. 修复建议

### 方案一：修改 Python 代码（推荐）

**位置**: `src/stage1/stage1_limit_detail.py` 第 92-108 行

**修改**: 在赋值给 `单一债券规模限额适用类别` 前，确保 `单一债券规模限额适用类别_base` 始终带尾斜杠（与 M 的 CombineColumns 行为一致）

```python
# 合并债券池（无条件拼接，与 M 代码 CombineColumns 行为一致）
if '债券池' in df.columns:
    df['单一债券规模限额适用类别_base'] = df.apply(
        lambda row: f"{row['单一债券规模限额适用类别_base']}/{row['债券池']}" 
        if pd.notna(row.get('债券池')) and row['债券池'] != ''
        else f"{row['单一债券规模限额适用类别_base']}/",  # 债券池为空时仍补尾斜杠
        axis=1
    )
else:
    # 无债券池列时，对非空 base 补尾斜杠
    df['单一债券规模限额适用类别_base'] = df['单一债券规模限额适用类别_base'].apply(
        lambda x: f"{x}/" if pd.notna(x) and x != '' else x
    )

# 处理中债隐含评级（保持不变）
df['单一债券规模限额适用类别'] = df.apply(
    lambda row: f"中债隐含评级{row['中债隐含评级']}" 
    if pd.notna(row.get('中债隐含评级')) and row['中债隐含评级'] in ['AAA', 'AAA+']
    else row['单一债券规模限额适用类别_base'],
    axis=1
)
```

### 方案二：修改配置表（不推荐）

在「单一债券规模限额」中增加无尾斜杠的 指标名称（如 `"国企"`、`"非国企"` 等），但会：
- 破坏配置表已有的规范（统一带尾斜杠）
- 需要为所有日期重复配置
- 不符合 M 代码的设计意图

## 9. 综合结论

### M 与 Python 在「债券池为空」时是否一致？

**❌ 不一致**

- **M**: 使用 `Table.CombineColumns({自定义, 债券池}, Combiner.CombineTextByDelimiter("/"))`，债券池 = null 时视为空字符串，得到 **"国企/"**（带尾斜杠）
- **Python**: 使用 `if pd.notna(债券池) else base`，债券池为 null 时保留 base，得到 **"国企"**（无尾斜杠）

### 应如何修改 Python？

**在合并债券池逻辑中（src/stage1/stage1_limit_detail.py 第92-97行），改为无条件拼接尾斜杠**：

```python
# 当前实现（错误）
if pd.notna(row.get('债券池')):
    return f"{base}/{债券池}"
else:
    return base  # ❌ 缺少尾斜杠

# 修复后（正确）
if pd.notna(row.get('债券池')) and row['债券池'] != '':
    return f"{base}/{债券池}"
else:
    return f"{base}/"  # ✅ 补尾斜杠，与 M 的 CombineColumns 行为一致
```

或更简洁：始终拼接，债券池为空时用空字符串

```python
债券池_str = row.get('债券池', '') if pd.notna(row.get('债券池')) else ''
return f"{base}/{债券池_str}"  # 始终有 "/"，与 M 一致
```
